# คู่มือเริ่มต้น — AI Procurement Assistant

โปรเจกต์ portfolio สำหรับแสดงความเข้าใจด้านจัดซื้อ การวิเคราะห์ต้นทุน SQL และการประยุกต์ AI โดยใช้ข้อมูลจำลอง ไม่ใช่ข้อมูลลูกค้าจริง

## เปิดใช้งานง่ายที่สุดบน Windows

1. แตกไฟล์ ZIP ให้เรียบร้อยก่อน อย่าเปิดโปรแกรมจากใน ZIP
2. ต้องมี Python 3.10 ขึ้นไป
3. ดับเบิลคลิก `START_WINDOWS.bat`
4. เบราว์เซอร์จะเปิด `http://127.0.0.1:8765`
5. ถ้าไม่เปิดเอง ให้คัดลอกที่อยู่นี้ไปใส่ใน Edge หรือ Chrome
6. ปิดโปรแกรมโดยกลับไปหน้าต่างคำสั่งแล้วกด Ctrl+C

ถ้าดับเบิลคลิกไม่สำเร็จ ให้เปิด Terminal ในโฟลเดอร์โปรเจกต์และพิมพ์:

```powershell
py -3 app.py --open
```

ไม่ต้องลงไลบรารีเพิ่มเติม และไม่ต้องมี API key สำหรับเปรียบเทียบต้นทุน

## วิธีทดลองให้เห็นคุณค่าของระบบ

- **Required quantity:** จำนวนที่ต้องการซื้อ
- **Deadline:** ต้องได้รับของภายในกี่วัน
- **Minimum quality:** เปอร์เซ็นต์คุณภาพขั้นต่ำที่ยอมรับ
- **Minimum OTIF:** สัดส่วนส่งตรงเวลาและครบจำนวนขั้นต่ำ
- **Run comparison:** คำนวณและจัดอันดับใหม่
- **Edit:** แก้ใบเสนอราคาของซัพพลายเออร์
- **Scoring weights:** กำหนดความสำคัญของต้นทุน ความเร็ว คุณภาพ และความน่าเชื่อถือ รวมต้องได้ 100%

เริ่มจาก BRG-6205 จำนวน 1,000 ชิ้น แล้วเปลี่ยน Deadline เป็น 1 วัน ระบบต้องไม่แนะนำซัพพลายเออร์ที่ส่งไม่ทัน หลังจากนั้นคืนเป็น 21 วัน แล้วลองให้น้ำหนักต้นทุน 100% เพื่อดูว่าตัวเลือกเปลี่ยนหรือไม่

## อ่านผลอย่างถูกต้อง

**Landed cost** คือต้นทุนตามแบบจำลอง ถ้าเลือกให้ VAT ขอคืนได้ ระบบจะไม่นำ VAT มารวมในต้นทุนที่ใช้จัดอันดับ

**Cash outlay** คือเงินสดตามแบบจำลองที่ต้องจ่ายรวม VAT แม้จะขอคืนได้ภายหลัง

**Cost vs. baseline** เป็นส่วนต่างจากซัพพลายเออร์ฐานที่เลือก ไม่ใช่กำไรจริงหรือยอดประหยัดที่เกิดขึ้นแล้ว

**Excluded** หมายถึงไม่ผ่านอย่างน้อยหนึ่งเงื่อนไข ระบบจะแสดงสาเหตุและไม่ให้ข้อเสนอนั้นชนะด้วยราคาถูก

**MOQ / pack size** อาจทำให้ต้องซื้อเกินความต้องการ ระบบแสดงจำนวนเกินและคิดต้นทุนจากจำนวนสั่งจริง

## บันทึกและส่งออก

- กด **Save decision** เพื่อตั้งชื่อและบันทึกในเครื่อง
- เปิด **Saved decisions** เพื่อโหลดเงื่อนไขเดิมมาคำนวณอีกครั้ง
- กด **Export comparison CSV** เพื่อนำตารางไปเปิดใน Excel
- กด **Download printable report** เพื่อรับรายงาน HTML เปิดในเบราว์เซอร์แล้วเลือก Print → Save as PDF ได้
- กด **Export calculation JSON** เพื่อดูค่าคำนวณและสมมติฐานอย่างละเอียด
- ข้อมูลที่ยังไม่กด Save จะหายเมื่อรีโหลดหน้าเว็บ

## เปิด AI จริง (ไม่บังคับ)

โหมดเริ่มต้นเป็นสูตรคำนวณและคำอธิบายตามกฎ ไม่ใช่ LLM

ถ้าต้องการให้ AI เขียนสรุปหรือคำถามสำหรับเจรจา ต้องมี OpenAI API key และ model ID ที่บัญชีใช้งานได้ ตั้งค่าใน PowerShell:

```powershell
$env:OPENAI_API_KEY = "YOUR_API_KEY"
$env:OPENAI_MODEL = "YOUR_AVAILABLE_MODEL_ID"
py -3 app.py --open
```

อย่าส่ง API key ให้ผู้อื่นหรือใส่ลง GitHub ค่า API แยกจากการรันโปรเจกต์แบบออฟไลน์ ตรวจค่าใช้จ่ายในบัญชี API ของตัวเอง

พิมพ์คำถาม เช่น **“ช่วยอธิบายเป็นภาษาไทยว่าทำไมควรเลือกผู้ขายรายนี้ และควรเจรจาเรื่องใด”** แล้วติ๊กยินยอมส่งข้อมูลก่อนกด Generate AI explanation

AI ได้รับข้อมูลการวิเคราะห์และชื่อผู้ขาย ต้องพิจารณาสิทธิในการส่งข้อมูลจริงก่อนใช้งาน ข้อความ AI อาจผิดได้ ให้ตรวจเทียบกับตาราง ตัวเลขและอันดับไม่ได้คำนวณด้วย AI

Repository ถูกสร้างแบบ Private เพื่อจำกัดการเข้าถึง ก่อนส่งให้ HR ดู ต้องเลือกว่าจะเปิด Public หรือให้สิทธิ์เฉพาะบุคคล


หลังขึ้น GitHub เปิด README ให้ HR ดูรายละเอียดและวิธีรันได้ แต่ GitHub Pages รัน Python backend ไม่ได้ จึงไม่ใช่ลิงก์เว็บแอปออนไลน์ทันที

## ถ้ามีปัญหา

- **Python not found:** ติดตั้ง Python 3.10+ และเปิด Terminal ใหม่
- **Port already in use:** ใช้ `py -3 app.py --port 8877 --open`
- **CSV error:** ดาวน์โหลด template แล้วคงหัวคอลัมน์และลำดับเดิม
- **No eligible supplier:** ตรวจวันหมดอายุ จำนวนสินค้า Deadline คุณภาพ และ OTIF
- **Weights must total 100:** แก้น้ำหนักรวมให้เท่ากับ 100
- **AI not configured:** โหมดเปรียบเทียบยังใช้ได้ปกติ ตั้ง environment variables แล้วเริ่มโปรแกรมใหม่หากต้องการ AI
